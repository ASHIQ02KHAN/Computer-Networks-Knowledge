# 🤝 Contributing to the Computer Networks Knowledge Repository

Thank you for your interest in contributing to this open-source Computer Networks learning platform! Our mission is to provide the highest-quality, most visual, mathematically rigorous, and accessible networking curriculum on GitHub.

---

## 🌟 How You Can Help

1. **Clarify Explanations:** Improve explanations of tricky concepts (e.g., TCP fast recovery, Dijkstra tie-breaking, ARP cross-subnet delivery).
2. **Add Visual Diagrams:** Contribute clean Mermaid diagrams or SVG/ASCII illustrations.
3. **Contribute Exam Walkthroughs:** Add verified, step-by-step solutions to university midterm and final exam questions.
4. **Code & Simulations:** Submit runnable Python simulations demonstrating protocol logic, checksums, or packet parsing.
5. **Fix Typos or Formatting:** Enhance readability, KaTeX equations, or table layouts.

---

## 📐 Template Standards

Whenever adding or updating a topic file, ensure that it strictly follows the **Standard 12-Section Learning Template**:

1. **Overview**
2. **Learning Objectives**
3. **Core Concepts**
4. **Visual Explanation** (with Mermaid / ASCII)
5. **Step-by-Step Mechanism**
6. **Real-Life Example**
7. **Practical Implementation** (Math / Python)
8. **Common Mistakes & Pitfalls**
9. **Practice Problems & Exam Walkthroughs**
10. **Knowledge Check (MCQs with Explanations)**
11. **Summary / Revision Cheat Sheet**
12. **References & Further Reading**

---

## 🌿 Contribution Workflow

1. **Fork the Repository** to your GitHub account.
2. **Create a Feature Branch:** `git checkout -b feature/topic-name`
3. **Make Changes:** Write clear Markdown with properly rendered KaTeX equations ($...$ and $$...$$).
4. **Verify Formatting:** Ensure all internal links and Mermaid diagrams render cleanly.
5. **Commit with Meaningful Messages:** `git commit -m "docs(transport): add selective repeat timeout derivation"`
6. **Push and Open a Pull Request!**

Thank you for helping empower thousands of computer science students worldwide!
